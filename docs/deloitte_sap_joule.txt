SAP Joule is SAP's generative AI copilot embedded across the SAP S/4HANA
Cloud suite. It uses large language models to help users query business
data in natural language, draft communications, and trigger workflows
without writing code.

In sourcing and procurement, Joule agents can be configured to evaluate
incoming RFQs (requests for quotation), extract key terms from supplier
responses, and flag contracts that fall outside pre-approved thresholds
for pricing or delivery timelines. This reduces the number of RFQs and
contracts that require full manual review by a human buyer.

Joule integrates with SAP Business Technology Platform (BTP), which
provides the extensibility layer for connecting Joule's agent framework
to a company's existing S/4HANA data model, without requiring a full
system rebuild. This makes it suitable for both greenfield (new)
implementations and brownfield (migrated from legacy systems)
S/4HANA deployments.
