Retrieval-Augmented Generation (RAG) is a technique for improving the
accuracy of large language model outputs by retrieving relevant
information from an external knowledge base before generating a
response, rather than relying only on what the model learned during
training.

A typical RAG pipeline has three stages. First, documents are split
into smaller chunks and converted into numerical vector representations,
either using sparse methods like TF-IDF or dense methods like neural
embedding models. Second, when a user asks a question, the question is
converted into the same vector space, and the system retrieves the
chunks most similar to the question using a distance metric such as
cosine similarity. Third, the retrieved chunks are inserted into the
prompt sent to the language model, which generates an answer grounded
in that retrieved context rather than from memory alone.

RAG is especially useful when the knowledge needed is private, recent,
or too large to fit in a single prompt, since it avoids the cost and
latency of fine-tuning a model on new data every time information
changes.
